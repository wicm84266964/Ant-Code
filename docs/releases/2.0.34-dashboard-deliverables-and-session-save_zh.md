# Ant Code v2.0.34：交付文件分栏与会话保存稳定性

发布日期：2026-11-13

本次补丁改善 Dashboard 文件查看、Windows 会话保存与源码更新兼容性。公开 CI、标签和线上发布状态以实际发布记录为准。

## 对用户工作流的直接变化

- Dashboard 右侧文件栏提供“过程动态 / 交付文件”切换。过程动态展示近期文件操作，交付文件依据成功完成回复中的本地文件链接识别，避免把中间草稿、失败回复或附件误当最终交付。
- 同一路径反复修改后刷新预览；主动打开文件后暂停自动跟随，可手动恢复。图片预览使用版本参数更新，桌面与移动端共用分类行为。
- 异步会话原子保存遇到短暂文件占用时，对 EPERM、EACCES、EBUSY 最多尝试六次，累计等待 300ms。持续失败仍报告错误并保留旧文件，不先删除目标或退化为原地覆盖。
- Windows 源码更新器不继承父 PowerShell 的模块搜索路径，避免 PowerShell 7 环境导致 Windows PowerShell 无法加载权限检查模块。原有私有目录权限校验保持严格。

## 配置、数据与安全边界

- 现有配置和会话可继续使用，无需迁移；不更改模型渠道、网络权限或用户项目内容。
- 交付栏是当前完成回复的视图，并非永久交付档案。无法定位文件名的内存图片及部分子智能体内部文件操作，不保证实时展示。
- 文件占用重试不能解决持续权限拒绝、断电窗口或 HTTP 503。网关默认重试行为未变，本次仅增加其回归断言。
- 自动化验证不代表所有私有研究数据、外部模型供应商和部署环境均已验证。

## 升级与产物位置

要求 Node.js 22.18 或更高。官方源码安装可使用 Dashboard 更新，或在安装目录执行 `git pull --ff-only`、`npm ci` 和 `npm run verify:install`。处理好活动任务后完全退出并重新启动 CLI/TUI、Dashboard，刷新页面；`ant-code --version` 应显示 `2.0.34`。

现有配置和 session 位置保持不变。本次发布源码和中文说明，无新增二进制附件，不发布 npm 包，不自动更新 TaxaMask 内嵌版本。
