# Ant Code v2.0.20：对话灯丝轨、记录搜索与项目路径复制

发布日期：2026-10-06

本版本是 Dashboard 小版本。长对话可以沿左侧灯丝回到已发送的提示；会话框按回车可在已保存的提示和回复里查找；当前项目路径可以一键复制。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 对话记录左缘增加灯丝轨。每条已发送提示对应一根暗金短丝，当前阅读位置有稳定亮点。悬停约 150 毫秒后，附近灯丝变长并展开标本签：序号、提示词和一行回复摘要。点击滚到该条输入并短时高亮，不把原文填回输入框。不足两条提示时不出现，窄屏隐藏。引导、唤醒和 Goal 续跑不占刻度。
- 提示很多时，轨最高约 420px，两端淡出表示上下还有。对话滚动时，当前灯丝停在轨的中部。指针放在轨上时，用滚轮浏览其余灯丝，悬停上下端不会自动滚动。
- 左侧搜索框打字仍只筛选标题、编号、模型和状态。输入完成后按回车，才搜索本机已保存的用户提示和 Ant Code 回复。结果列在会话列表上方，不替换标题筛选。点一条打开该会话并跳到对应内容。
- 「当前项目」路径旁增加「复制」按钮。路径尚未载入或连接失败时按钮不可用。

## 配置、数据与安全边界

- 不改变权限模式、凭据存储、网关配置或 session 文件格式。
- 内容搜索只读取当前项目本机已保存的可见提示和回复，不建立外发索引。无法读取的会话只计数，不返回原文。每个会话最多 3 处，一共最多 30 处。
- 现有 session 可继续打开，无需重建。
- 自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.20`。正在运行的 Dashboard 需要重启并刷新浏览器，搜索接口才会生效。现有网关配置和 `.lab-agent` 会话不必重建。

## 验证、限制与待完成门禁

- 开发仓已运行内容搜索单元测试、灯丝轨单元测试、Dashboard UI 单元测试、Dashboard 服务路由测试，以及浏览器中的灯丝轨跳转、项目路径复制和无严重无障碍问题检查。候选阶段的正式仓 `verify:release`、CI、tag 和 GitHub Release 完成后才会记入发布记录。
- 已知限制：尚未载入页面的更早提示不会提前出现在灯丝轨上；内容搜索没有持续进度条，记录少时会很快返回；完全相同的短句可能跳到先载入的那一处。最终结论以正式仓同一提交的 CI 和 Release 门禁为准。
