# Ant Code v2.0.27：思考过程收起工具，未测档位不再默认 max

发布日期：2026-10-20

本版本整理 Dashboard 里已经完成的一轮对话，并收紧未测出思考档位时的默认名单。这是兼容性修复。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 最终回复出现后，工具条和「思考 · 第 N 轮」按出现顺序收进同一个「思考过程」。和最终回复相同的那一段正文不再重复贴进折叠。
- 工具仍是窄条。成功是绿线和勾，失败是淡红底和叉，被阻止是琥珀色。展开后仍是最多 1000 字的结果摘录。
- 没有测出思考档位的模型，默认名单改为 low、medium、high、xhigh。不再因为名字像 GPT 或 DeepSeek 就额外加上 max。
- 路线自己声明过、或目录测试实际测出的档位仍按测到的结果保留。

## 配置、数据与安全边界

- 不改变权限模式、凭据存储或会话正文。已有配置和会话可以继续使用。
- 以前自动写入、但没有探测记录的 max 名单，运行时改按四档使用。已经测出的档位不会被清掉。
- 工具摘录仍不送回模型。自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.27`。正在运行的 Dashboard 需要重启并刷新浏览器。

## 验证、限制与待完成门禁

- 开发仓已运行思考档位、会话选择和界面折叠相关的单元测试。候选阶段的正式仓 `verify:release`、CI、tag 和 GitHub Release 完成后才会记入发布记录。
- 已知限制：隐藏的长思考仍不展开。最终结论以正式仓同一提交的 CI 和 Release 门禁为准。
