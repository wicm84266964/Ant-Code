# Ant Code v2.0.16：Dashboard 会话搜索、自动起名与模型能力观测

发布日期：2026-09-18

本版本是 Dashboard 工作流小版本。旧工作目录残留的过期 agent 路由不再拦住启动；左侧栏可搜索会话，并可用 cheap 模型给新会话起名；设置页用真实请求确认视觉和思考能力，不再只靠勾选或非法档位负控。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 在曾经用过 Ant Code、仍留有过期 `.lab-agent/config.json` 的目录里启动 Dashboard，不再因找不到 `deepseek-v4-pro` 这类旧模型名而失败；缺失路由会被跳过，落到当前全局模型。
- 左侧栏可按标题、会话 ID、模型和状态过滤当前列表。
- 第一次真正发任务时，若配置了独立的 cheap 模型，会在主任务之外异步起一个不超过 28 字的标题；失败则仍用第一条用户输入。标题不进主会话 transcript。
- 设置页点选发现的模型后会自动探测视觉：发一张 64×64 灰图，网关收下则勾上「视觉」。探测使用已保存 Key，不把 Key 填回输入框。
- 「检测档位」改为观察返回里有没有思考内容（含 `reasoning_tokens`），不再发送非法档位，也不再扫 8 档。反代若只确认会思考、不提供档位列表，需要手勾强度后保存。

## 配置、数据与安全边界

- 不改变权限模式、凭据存储格式或 session/transcript 结构。
- 现有网关配置和会话可继续使用；探测结果只有写入模型设置后才会影响之后的传图和思考请求。
- 自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。第三方反代若不返回思考正文或不接受探测图，仍可能显示无档位或无结论。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.16`。正在运行的 Dashboard 需要重启并硬刷新浏览器。现有网关配置和 `.lab-agent` 会话不必重建。
