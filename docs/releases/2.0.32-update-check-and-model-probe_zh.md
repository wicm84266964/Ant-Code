# Ant Code v2.0.32：更新检查不再误拦，模型测试档位即时生效

发布日期：2026-10-30

本次修复 Dashboard 源码更新检查被日常 Git 配置阻止，以及目录模型测试结果没有应用到思考强度选择器的问题。此说明记录候选验证状态，不提前声称公开 CI、tag 或 GitHub Release 已完成。

## 对用户工作流的直接变化

- 检查版本不再要求聊天空闲，也不关闭其他 Dashboard。真正安装时仍要求任务结束，并协调其他空闲窗口；不会自动取消运行、排队或待确认的任务。
- 更新 Git 子进程隔离个人和系统配置，避免日常凭据助手、URL 重写、TLS 设置造成误拦或改变更新路线；仓库本地危险配置仍被拒绝。
- 模型目录的“测试”将确认的思考档位保存到模型所属配置层，并刷新聊天栏。例如确认 `off/high/max` 后使用这些档位，不再恢复为通用低、中、高、极高。
- 明确的视觉测试结论也会保存。没有确认档位、请求失败或扫描超时时保留原档位，不用残缺结果覆盖已有配置；新增 `minimal` 档探测。

## 配置、数据与安全边界

- 保留 V2 配置与凭据分离、修订冲突检查和模型其他元数据。并发修改配置后，旧测试结果不能覆盖新配置。
- 不修改个人 Git 配置。代理仍独立发现并使用确定路线，不静默切换直连或降低 TLS 校验。
- 更新仍限独立官方 HTTPS Git 源码安装；缺少官方上游、工作区不干净、分叉或不安全仓库状态仍会阻止操作。不自动 stash、reset、clean 或强制覆盖。
- 不重建会话或用户研究文件。自动测试不能代表所有私有研究数据、外部供应商或部署环境已经验证。

## 升级与产物位置

要求 Node.js 22.18 或更高。若旧版更新按钮仍被旧规则阻止，本次先在源码安装根目录手动升级：

```sh
git pull --ff-only
npm ci
npm run verify:install
ant-code --version
```

版本应为 `2.0.32`。完全退出旧 CLI、TUI 和 Dashboard 后重新启动；同一源码安装已有正确的全局链接时无需再次 `npm link`。重新点击模型“测试”后，确认结果会保存并刷新。未测试模型继续使用已有配置或通用档位。

源码及本说明随 Git tag 提供；更新日志仍位于安装仓库私有的 `.git/ant-source-update/`。本次没有新增二进制附件，不更新 Windows 成品包、TaxaMask 内嵌副本，也不发布 npm 包。
