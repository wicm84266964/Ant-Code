# Ant Code v2.0.30：后台子任务结果并入当前会话

发布日期：2026-10-26

本版本改变后台子任务完成后交回主控的方式。多个组的完成报告不再各排成一条新的接续会话，而是在当前会话的下一处安全边界一次交回。这是兼容性修复。候选阶段不表示正式仓 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 主控还在工作时，后台子任务完成不会打断当前模型响应或正在执行的工具，也不会逐条排队等待主控结束后再一条条接收。
- 已经到齐的组报告会合成一条交接。当前这批工具返回后、下一次请求模型之前插入当前轮；主控准备结束本轮时，如果还有未交回的结果，会先交回再汇总。
- 主控已经空闲时，短合并后只开一轮接续，带上当时到齐的全部报告。接续轮进行中又完成的组，在该轮下一次模型请求前补入。
- 引导和随后发送的用户消息仍然优先。待交回的子任务报告附在那一轮里，不排成后面的独立会话。
- 界面仍按组显示完成。模型只看到一条交接。已有配置和会话可以直接继续使用，不需要迁移。
- 一并带上 2.0.29 发布后已在开发版验证、此前未公开的 Windows 源码更新清理修正：进程树清理继续使用原有最终预算，不再提前截断。

## 配置、数据与安全边界

- 不新增配置字段，不重建会话、凭据或本地项目文件。任务组记录仍在本机 `.lab-agent/task-groups` 与 `.lab-agent/tasks`。
- `wakePromptConsumedAt` 改到交接报告进入模型请求时写入，不再在排队时提前标记已消费。
- 自动化测试不能代表所有私有研究数据、外部模型供应商或部署环境都已验证。本次不读取或发布真实会话内容。

## 升级与产物位置

需要 Node.js 22.18 或更高。已经在 2.0.29 且符合源码更新条件的安装，可用 Dashboard 左上角“更新”升到本版本。从尚无更新按钮的旧版首次升级，仍须在源码安装根目录手动执行：

```sh
git pull --ff-only
npm ci
npm run verify:install
npm link
ant-code --version
```

版本应显示 `2.0.30`。退出旧的 CLI、TUI 和 Dashboard 再启动；只更新磁盘代码不会让旧进程改用新的交接方式。

本次不更新 Windows 成品包或 TaxaMask 内嵌副本，也不发布 npm 私有包。没有新增成品下载包。
