# Ant Code v2.0.35：Dashboard 快速模式与断线续聊

发布日期：2026-11-23

本次补丁加入可选的 Dashboard 快速模式，并修复首轮网关无响应后续聊缺少用户消息的问题。

## 对用户工作流的直接变化

- 输入框底部新增「快速」开关，默认使用常规模式。快速模式适合查资料、读文件和小改动，由主模型直接处理，沿用工作区、网络和 MCP 权限。每条排队消息保留发送时选定的模式，Goal 续跑使用常规模式。
- 查资料时，快速模式可以在简短总结中引用最多两段工具返回的原文，附可用的出处和定位信息。搜索摘要单独标注，抓取失败作为失败报告。
- 用户消息在模型请求前保存。网关零响应后，在同一会话切换网关再发「继续」，已保存的用户消息可随本轮请求送出。运行中刷新继续通过实时事件显示当前轮。
- 文档读取超限或格式不受支持时，工具返回具体失败原因。输入文件大小限制、预览输出上限和文件访问审批沿用既有规则。

## 配置、数据与安全边界

- 现有配置、会话和工作区文件可继续使用，无需迁移。会话保存沿用已有保留、脱敏和加密配置。旧版本已经遗漏的消息需要重发，历史图像在续聊时也需要重新附上原图。
- 快速模式由当前模型直接接收图片，使用纯文本模型时可切换到支持图片的模型，或在已配置视觉模型的网关下使用常规模式。自动化验证覆盖模拟来源和已配置工具的调用路径，私人数据与外部供应商仍以各自运行结果为准。

## 升级与产物位置

需要 Node.js 22.18 或更高。官方源码安装可通过 Dashboard 更新，或在安装目录执行 `git pull --ff-only`、`npm ci` 和 `npm run verify:install`。退出并重启 CLI/TUI 和 Dashboard，刷新页面后运行 `ant-code --version`，应显示 `2.0.35`。

本次提供 GitHub 源码与中文发布说明。现有会话保留在原位置，TaxaMask 内嵌版按其独立流程更新。
