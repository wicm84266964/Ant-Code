# Ant Code v2.0.4：满窗口压缩、超限取消发送与 Goal 界面

发布日期：2026-09-02

这是 2.0 TypeScript 运行时上的小版本修复。自动压缩改为等到配置的上下文窗口满了才触发；后续网关轮次先压飞行中的工具结果，不够再摘要历史；两边压完仍超窗口时，本轮在本地取消发送，避免网关 HTTP 400。Dashboard Goal 长目标不再撑破状态条，输入栏淡提示也不再被 Goal 文本替换。权限模式 id 不变。本说明处于公开发布候选阶段，不表示 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 历史压缩和飞行中工具压缩的默认阈值都是配置窗口的 100%。配置里写了压缩比例，就按这个比例用，`1` 表示满窗口。
- 第 0 轮仍只压缩旧会话。工具结果落地后的后续轮次：先压飞行中的工具结果，仍超再摘要历史；若还超，再压一次工具结果。
- 压缩后估算仍超过窗口时，不再把超长请求发给网关。TUI / Dashboard 显示「上下文超出窗口」，本轮记为 `context_overflow` 并取消发送。
- Dashboard Goal 状态条：文案区可以收缩；完成、失败或预算暂停时目标单行省略；进行中最多三行；续跑原因可折行。完整目标仍在 `title` 悬停提示里。
- 启用 Goal 后，底部输入栏的淡色占位提示保持原来的任务需求示例。Goal 文本只出现在上方状态条，不再写进输入栏 placeholder。

## 配置、数据与安全边界

- 配置格式、session / transcript、凭据存储和网关协议没有迁移。现有 `lab-agent.config.json` 和 `.lab-agent` 会话可继续使用。
- 这次没有改权限模式 id，也没有改网关选择逻辑。
- `context_overflow` 是本机取消发送，不会把已经超窗的提示词交给上游。会话记录会留下这次取消，不会偷偷重试同一超长请求。
- 自动化测试不能代表所有私有研究数据、外部模型供应商或现场部署环境都已得到验证。

## 升级与产物位置

需要 Node.js 22.18+。从源码更新：

```sh
git pull
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.4`。若以前 link 过旧安装，需要重新 `npm link`。正在跑的 Dashboard 需要重启后才会用到这次修复。现有网关配置和会话不必重建。本次没有新的安装包、审计报告或日志目录要求。
