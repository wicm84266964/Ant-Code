# Ant Code v2.0.1：黑金界面与会话区拖选复制

发布日期：2026-08-31

这是 2.0 TypeScript 运行时上的小版本。默认 TUI 和 Dashboard 改为黑金；会话区拖选只复制聊天文字；并带上搜索后端收敛和 Windows 后台终端修复。权限模式 id 不变。本说明处于公开发布候选阶段，不表示 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- TUI 默认主题改为 `gold-black`。未设置 `LAB_AGENT_TUI_THEME` 时，成功态和强调色都走金色，不再用薄荷绿。`LAB_AGENT_TUI_THEME=sky-blue` 仍可切回旧天蓝主题。
- TUI 会话区按住拖选，松手后把可见聊天行写入系统剪贴板，不含圆角边框和右侧栏。单击仍是选中块，双击仍打开摘录。终端原生整行复制仍会带上同排单元格，所以拖选由应用接管。
- Dashboard 同步为黑金工作台：更黑的底、金色强调、Goal 与权限三段同组，上下文条改为缓存命中率，空状态和设置/附件图标更新。权限 radio 仍是 `plan` / `workspace` / `fullAccess`。
- 可取消的后台任务在 Dashboard 顶部 live chip 上提供「回收」。
- `/keybindings` 说明与会话区焦点一致：Tab 在输入区和会话区之间切换，`y` 复制当前块，Shift+方向键切换侧栏。
- `web_search` 只使用内置 DuckDuckGo HTML；`duckduckgo-search` MCP 默认关闭。`web_fetch` 仍可走 `fetch` MCP。已配置的自建 SearXNG 仍可用。
- 面向用户的文案不再把当前产品写成 clean-room MVP。

## 配置、数据与安全边界

- 配置格式、session / transcript、凭据存储和网关协议没有迁移。现有 `lab-agent.config.json` 和 `.lab-agent` 会话可继续使用。
- 未设置 TUI 主题的用户会看到默认配色变化；这是界面默认值，不是配置文件强制改写。
- 项目里已经显式启用 `duckduckgo-search` MCP 的配置不会被这次发布改掉；仓库推荐项和内置搜索默认改为关闭该 MCP、走 DuckDuckGo HTML。
- 自动化测试不能代表所有私有研究数据、外部模型供应商或现场部署环境都已得到验证。

## 升级与产物位置

需要 Node.js 22.18+。从源码更新：

```sh
git pull
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.1`。若以前 link 过旧安装，需要重新 `npm link`。现有网关配置和会话不必重建。Dashboard 若仍显示旧皮肤，硬刷新浏览器静态资源即可。本次没有新的安装包、审计报告或日志目录要求。
