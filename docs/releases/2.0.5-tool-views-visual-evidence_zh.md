# Ant Code v2.0.5：工具结果短视图与视觉证据卸像素

发布日期：2026-09-04

这是 2.0 TypeScript 运行时上的小版本修复。发给模型的工具结果改为按工具裁剪的短视图，不再默认整包 pretty JSON；本轮超过最近四条的旧工具结果会提前占位，不必等窗口满。用户附图和工具截图登记为会话内视觉证据：主模型第一轮仍可看图，一旦开始调工具，后续请求不再重放原图像素。`visual-verifier` 可通过 `evidenceIds` 继续看图。权限模式 id 不变。本说明处于公开发布候选阶段，不表示 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 父会话和子智能体发给模型的工具输出是短视图：读文件给行号片段，搜索限制条数，命令保留头尾，写入结果几乎不带完整 diff。32KB 仍是硬安全阀。
- 同一轮里，超过最近四条的工具结果会收成一行占位。需要细节时再读文件或再跑同一工具。
- 用户附图仍在第一轮发给视觉主模型。开始调用工具后，主上下文只保留证据编号占位，不再附带图片 base64。
- MCP 等工具返回的图片不会以 base64 进入工具 JSON；会留下证据编号。
- 把视觉任务交给 `visual-verifier` 时，可传入 `evidenceIds`；不传则自动带上待处理证据。
- TUI 与 Dashboard 的上下文用量优先显示即将发给网关的 live 估计，而不只显示已经落盘的历史对话。

## 配置、数据与安全边界

- 配置格式、session / transcript、凭据存储和网关协议没有迁移。现有 `lab-agent.config.json` 和 `.lab-agent` 会话可继续使用。
- 这次没有改权限模式 id，也没有改网关选择逻辑。
- 图片像素仍然不会写入 session 文件；历史里只保留 `redacted` 摘要。视觉证据只活在当前进程内存里，resume 后不能恢复原图像素。
- 同一网关 / 同一 Key 边界不变，不会跨厂商借视觉模型。
- 自动化测试不能代表所有私有研究数据、外部模型供应商或现场部署环境都已得到验证。

## 升级与产物位置

需要 Node.js 22.18+。从源码更新：

```sh
git pull
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.5`。若以前 link 过旧安装，需要重新 `npm link`。正在跑的 Dashboard 需要重启后才会用到这次修复。现有网关配置和会话不必重建。本次没有新的安装包、审计报告或日志目录要求。
