# Ant Code v2.0.17：失败与中断后保留草稿、思考过程和子任务进展

发布日期：2026-09-21

本版本是 Dashboard 与子智能体恢复小版本。网关失败或上游断流时，对话区立即显示报错，并把已经流出的可见草稿写入会话；正常完成的一轮会保留「思考过程」折叠条。子智能体被停止或断流时，已完成的工具调用和可见草稿写入任务记录，主控稍后查阅即可捡回。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- Dashboard 模型请求失败时，错误会出现在对话区，不必整页刷新。
- 第一个会话如果失败，刷新后仍打开该会话，不再回到「我将全力配合你的工作」空首页。
- 上游中途断开时，已经贴出的可见草稿留在对话里，并标成「已中断 · 非最终回复」；刷新后仍在。
- 正常最终回复到达后，「思考过程」折叠条与最终回复一起保留，刷新后两者都还在。
- 子智能体中断或断流时，不自动唤醒主控；任务记录里保留已完成工具和可见草稿，可用任务详情或 `/agents continue <task-id>` 继续。
- 子智能体发给网关的请求改为流式，便于在断流时截取可见草稿。内部 thinking 正文仍不作为可见汇报展开。

## 配置、数据与安全边界

- 不改变权限模式、凭据存储格式或网关配置格式。
- 会话 transcript 会多出中断草稿和思考过程条目；现有 session 可继续打开，无需重建。
- 子智能体任务记录会写入中断时的 output、toolCalls 和 continuationPrompt。
- 自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.17`。正在运行的 Dashboard 需要重启并硬刷新浏览器。现有网关配置和 `.lab-agent` 会话不必重建。
