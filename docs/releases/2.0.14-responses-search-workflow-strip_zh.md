# Ant Code v2.0.14：Responses 搜索不再掐断，任务进度只留顶部栏

发布日期：2026-09-14

这是 2.0 TypeScript 运行时上的小版本。Responses 网关夹带托管搜索时不再把整轮标成失败；Dashboard 待办和计划只显示在顶部任务条。设置按钮齿轮改为上下左右对称。权限模式 id 不变。本说明处于公开发布候选阶段，不表示 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 使用 Grok 等 Responses 协议网关时，上游若返回原生 `web_search_call`，聊天不再报协议错配并中断。本轮若还有本地工具调用或可见正文，会继续执行。Chat Completions 协议不受影响。
- Dashboard 待办清单和任务计划只保留在顶部「任务进度」条，可展开查看。聊天记录不再插入同一份进度面板，也不再刷「任务状态已同步」。
- 设置按钮的齿轮图标改为八齿对称图形，避免看起来缺角。

## 配置、数据与安全边界

- 不要求手动迁移配置或历史会话。已有网关、权限和 `.lab-agent` 会话可继续使用。
- 托管搜索事件仍只记在内部原始载荷里，不会伪装成本地 `web_search` 工具结果。
- 本次不更新其他产品的内嵌运行时，不同步真实会话、凭据或研究数据。自动化测试不等于所有外部模型供应商都已验证。

## 升级与产物位置

需要 Node.js 22.18+。从源码更新：

```sh
git pull
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.14`。若以前 link 过旧安装，需要重新 `npm link`。正在跑的 Dashboard 需要重启并硬刷新浏览器。现有网关配置和会话不必重建。

## 验证、限制与待完成门禁

- 开发阶段已覆盖 Responses 托管搜索不中断、待办/计划只更新顶部栏，以及设置图标路径。
- 开发仓完整 `npm run check` 与跨仓一致性检查在脱敏同步时记录实际数字。候选提交后仍须 GitHub PR 和 main CI 通过，随后创建标签与 Release；实际完成状态记录在公开 CHANGELOG。
- 未对每个外部模型供应商做真实账户验收。托管搜索若既无本地 tool call 也无可见正文，仍可能走空正文或短停兜底，不会再以协议错配失败。
