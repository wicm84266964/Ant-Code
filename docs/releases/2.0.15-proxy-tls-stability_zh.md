# Ant Code v2.0.15：代理 TLS 断连稳定性修复

发布日期：2026-09-18

本版本修复内置 HTTPS 代理在 TLS 握手期间断开连接时可能导致 Dashboard 进程退出的问题。

## 对用户工作流的直接变化

- 代理 TLS 握手失败后，Dashboard 保持运行并将网络错误返回给当前请求。
- 代理响应 socket 在关闭前持续处理错误事件，关闭后清理监听器。

## 配置、数据与安全边界

- 不改变代理选择、重试、TLS 证书校验、权限、网关配置或 session 数据格式。
- 不新增凭据或网络端点。自动化测试不覆盖所有外部代理和模型供应商环境。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

现有网关配置和 session 可直接继续使用；运行中的 Dashboard 需要重启。

- 代理 TLS 回归及工具单元测试：105 passed，0 failed。
- 类型、语法和依赖策略检查通过；公开仓 release verification 通过。
