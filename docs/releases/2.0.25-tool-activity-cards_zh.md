# Ant Code v2.0.25：工具调用留在对话流程里

发布日期：2026-10-20

本版本让 Dashboard 在长任务里看得到工具调用，并在展开后显示一段可读结果。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 工具开始时，对话里按顺序出现一张活动卡，跟在「思考 · 第 N 轮」后面。完成后同一张卡改为已完成、失败或被阻止。失败不再另出一张卡。
- 展开活动卡可以看到最多 1000 字的结果摘录。读文件是带行号的片段，搜索是路径和匹配行，命令是输出头尾，改文件是增删统计和一小段 diff。
- 重新打开会话仍能看到这些工具卡。完整工具结果仍只交给模型，不进入可见对话全文。
- 模型来源编辑页会回填已保存的路线名。模型目录可以测试当前路线，并查看视觉结果和接受的思考档位。
- 新会话在第一份快照写出之前切换模型或思考档位，不再报「模型选择未能安全保存」。
- 如果路线明确拒绝当前思考档位并列出可接受的值，本轮会改用其中最高档再请求一次。

## 配置、数据与安全边界

- 不改变权限模式、凭据存储或路线名的保存规则。已有配置和会话可以继续使用。
- 工具卡写入会话记录，供刷新和重新打开后查看。这段记录不送回模型，也不包含密钥。摘录超过 1000 字会截断。
- 模型内部思考仍默认隐藏。自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.25`。正在运行的 Dashboard 需要重启并刷新浏览器。

## 验证、限制与待完成门禁

- 开发仓已运行 Dashboard 事件映射、会话模型选择、模型目录测试和工具记录的单元测试。候选阶段的正式仓 `verify:release`、CI、tag 和 GitHub Release 完成后才会记入发布记录。
- 已知限制：模型思考字段里的长过程仍不展开。可见正文如果自带思考标记，仍会原样出现在「思考 · 第 N 轮」。最终结论以正式仓同一提交的 CI 和 Release 门禁为准。
