# Ant Code v2.0.21：会话列表拖动条与永久保留

发布日期：2026-10-09

本版本是 Dashboard 与会话保留策略的小版本。左侧任务线程超出画面时可以拖动滚动条查看下面的会话；没有单独写保留期限时，会话记录默认永久保留。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 左侧任务线程很多时，列表右侧出现可拖动的滚动条。按住滑块可以查看下面的会话，点击轨道会跳到对应位置。搜索标题和按回车搜索已保存记录的行为不变。
- 配置里没有写 `transcript.retentionDays` 时，不再按 30 天清理会话。缺省改为永久保留。
- 设置页里已经写成具体天数的项目，仍按那个天数清理。写成 `0` 时仍不保留。高敏感度项目仍强制零保留。

## 配置、数据与安全边界

- 不改变权限模式、凭据存储、网关配置或 session 文件格式。
- 更新不会改写已经保存的配置文件。只有没写保留期限的配置才会跟着新的缺省值走。
- 现有 session 可继续打开，无需重建。
- 自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.21`。正在运行的 Dashboard 需要重启并刷新浏览器，拖动条和新的保留缺省才会生效。现有网关配置和 `.lab-agent` 会话不必重建。

## 验证、限制与待完成门禁

- 开发仓已运行会话存储与保留期限单元测试、配置加载测试、doctor 测试、Dashboard UI 单元测试，以及浏览器中长会话列表拖动到最后一条的检查。候选阶段的正式仓 `verify:release`、CI、tag 和 GitHub Release 完成后才会记入发布记录。
- 已知限制：已经在配置里写明天数的项目不会因为这次更新自动改成永久保留；收起左侧栏后仍可用滚轮浏览会话，拖动条在收起时隐藏。最终结论以正式仓同一提交的 CI 和 Release 门禁为准。
