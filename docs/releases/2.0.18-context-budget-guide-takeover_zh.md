# Ant Code v2.0.18：长会话按摘要加短尾巴压缩，引导接管不再显示中断

发布日期：2026-09-22

本版本是上下文预算与引导纠偏小版本。长会话发给模型的下一包请求改为「系统说明 + 交接摘要 + token 封顶短尾巴」，当前轮工具也会进入压缩；子智能体复用同一套发送前预算门。压缩腾出窗口后如果模型只返回隐藏 thinking，会自动重试一次。排队后点引导时，界面显示「引导已接管」，不再写成任务中断。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 长任务接近本地上下文上限时，下一包请求按摘要加短尾巴重建，当前轮已经很长的工具调用也会被压缩，避免把整段工具链原样拼回去后超窗。
- 工具正文收短后如果仍刚过窗口，会继续收更早的 thinking 和当前轮更早的工具轮，只留最近一轮配对；压不进窗口时取消发送，避免网关 400。
- 子智能体在自己的模型请求前走同一道预算门。中间工具噪声留在子任务里，交还主控仍是报告；压完仍超窗则阶段汇报，不再发超限请求。
- 压缩后模型把整轮放进隐藏 thinking、界面没有可见正文时，会重试并要求写出可见回复或继续调用工具。
- TUI 和 Dashboard 里，插入排队消息并点引导后显示「引导已接管」；Esc / Ctrl+C / 引导停止仍显示中断。
- 从 Dashboard 续跑时，如果整包归档已经超过发送窗口，会改回已压缩上下文或再压一版，避免把超限历史整包灌回网关。

## 配置、数据与安全边界

- 不改变权限模式、凭据存储格式或网关配置格式。
- 磁盘上的 transcript 仍保留全文；发给模型的活跃上下文从最新摘要加短尾巴重建。图片在会话上下文里仍只保留红行摘要。
- 现有 session 可继续打开，无需重建。续跑时可能看到已压缩的短尾巴，而不是整包归档原文。
- 自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。
