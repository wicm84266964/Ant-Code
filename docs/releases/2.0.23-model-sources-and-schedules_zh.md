# Ant Code v2.0.23：模型来源与定时任务整理

发布日期：2026-10-18

本版本整理 Dashboard 的模型来源和定时任务。添加来源时一次读入目录，聊天按路线名切换模型。定时任务可以在设置里查看和手动管理。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 添加模型来源时填写路线名、地址、协议和密钥，保存后写入这次读到的全部模型。同一地址的不同密钥用不同路线名，不再互相覆盖。
- 同一渠道里同时有裸名和带前缀的模型 id 时，列表优先保留带前缀的 id。
- 聊天栏按路线名切换模型。没有声明思考档位的第三方模型可以使用通用档；DeepSeek、GPT 等家族包含 max。
- 模型目录可以指定当前项目或全局默认模型，并显示「此范围默认」。当前会话模型仍在聊天栏切换。
- 子智能体模型按渠道单独保存，只使用该渠道的模型。
- 配置了视觉子智能体时，图片和扫描版 PDF 交给它。没配置时，图片直接发给主模型；上游拒绝看图时给出提示。
- 设置页增加定时任务。可以只跑一次、每天、每周或按间隔重复。星期用下拉框选择。时间框预填格式，中文冒号和全角数字也可以识别。
- 工具失败仍只留一行轻提示。用户停止、引导接管、上游断开和整轮失败仍显示已中断或失败。

## 配置、数据与安全边界

- 定时任务保存在当前项目的 `.lab-agent/schedules/`。到点运行使用完全访问，创建或设置页添加时的确认就是这次授权。
- 现有会话和已保存的来源可以继续使用。旧的单模型档案不会自动合并。
- 未声明思考档位的模型不再因为已保存的推理档拦住 Dashboard 启动。
- Dashboard 进程没开时不计时。重新打开后，错过的轮次只补一次。
- 自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.23`。正在运行的 Dashboard 需要重启并刷新浏览器。

## 验证、限制与待完成门禁

- 开发仓已运行定时任务、推理档位和目录导入相关单元测试。候选阶段的正式仓 `verify:release`、CI、tag 和 GitHub Release 完成后才会记入发布记录。
- 已知限制：定时任务依赖本机 Dashboard 进程；间隔重复最短 15 分钟；一次性任务最短 1 分钟、最远 7 天。路线名需要以字母开头。最终结论以正式仓同一提交的 CI 和 Release 门禁为准。
