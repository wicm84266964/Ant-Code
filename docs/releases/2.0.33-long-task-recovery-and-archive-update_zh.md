# Ant Code v2.0.33：长任务断线恢复与官方备用更新

发布日期：2026-11-06

本次补丁修复长任务期间 Dashboard 显示离线、后台仍在继续执行时，页面无法持续重连和恢复状态的问题；增加工具执行检查点，以及 GitHub Git 直连失败后的官方归档备用更新。候选阶段的 CI、tag 和 GitHub Release 状态以线上记录为准。

## 对用户工作流的直接变化

- Dashboard 历史事件按连接可接收的速度回放，避免长历史在重连时瞬间挤满发送缓冲。重试间隔最多 15 秒并持续重连；浏览器外网离线提示不再阻断本机连接，返回页面时检查陈旧连接。
- 重连后同步当前任务、Goal、队列、权限及待回答问题，清理失效交互并保留同一问题的草稿。历史事件不足时提示缺口，不把页面离线误判为后台任务已结束，也不自动重发任务。
- 每批已完成工具调用保存配对结果和恢复上下文，再允许下一操作。写工具逐项保存，存储失败会阻止下一操作；暂停、网关错误和正常结束保留已完成记录并避免重复归档。工具状态使用结构化结果，避免把紧凑显示文本误报为失败。
- 源码更新明确选择“仅本次直连”后，Git fetch 或上游查询失败时自动尝试官方 `api.github.com` 与 `codeload.github.com`。校验真实提交、源码树及缺失历史后，继续原有依赖准备、快进、原端口重启和新实例核验流程。

## 配置、数据与安全边界

- 现有配置和会话可以继续使用，无需迁移。检查点使用原有会话存储与脱敏/加密边界；本次不重写历史会话、补造旧事故中已缺失的记录或修改用户项目产物。
- 外部工具副作用与本地检查点不是原子事务。进程被强杀或断电恰好发生在两者之间时，仍须核验实际文件和工具结果，不能承诺恰好执行一次。
- 官方归档按固定提交下载，在内存中受限解析并重建 Git 对象，要求提交及文件树哈希匹配；不把压缩包直接覆盖到安装目录。检查失败不改变 HEAD、已检出源码或原依赖，可能留下可复用的已验证无引用对象。
- 代理失败不会擅自直连。现有干净工作区、官方上游、祖先关系、权限、活动任务、候选依赖和重启 ACK 保护保留；不自动 stash/reset/clean、强制覆盖或取消任务。
- 自动化检查与本机用户试用不能代表所有私有数据、模型供应商和部署环境均已验证。

## 升级与产物位置

要求 Node.js 22.18 或更高。符合条件的独立官方源码安装可使用 Dashboard 更新；旧版本尚不具备本次备用通道，若首次升级被 GitHub 网络阻止，请先配置可用 HTTP(S) 代理，或在安装根目录手动升级：

```sh
git pull --ff-only
npm ci
npm run verify:install
ant-code --version
```

版本应显示 `2.0.33`。升级前处理活动任务，完全退出旧 CLI/TUI 和 Dashboard 后重新启动并刷新页面；同一安装已有正确全局链接时无需再次 `npm link`。配置与会话保持原有位置，更新 journal、候选和旧依赖备份位于安装仓库私有的 `.git/ant-source-update/`。

本次仅发布源码及中文说明，无新增二进制附件，不更新 Windows 成品包或 TaxaMask 内嵌副本，不发布 npm 包。详细操作和恢复边界见 [源码更新说明](../deployment/source-self-update.md)。

- 覆盖长历史回放、离线重连、权限/提问恢复、工具检查点及存储失败；备用更新覆盖缺失对象导入、损坏拒绝、合并历史写入中断后的重试，以及临时安装中独立 worker 的依赖准备、Git 快进、原端口重启和新实例 ACK。
- 已只读验证官方当前公开提交的 API 元数据、签名提交重建及 codeload 文件树哈希；这不等同于真实公网安装升级。本机用户试用未报告问题，不扩大为所有环境的人工验收。
