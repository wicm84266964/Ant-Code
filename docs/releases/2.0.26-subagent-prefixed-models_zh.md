# Ant Code v2.0.26：子智能体下拉保留带前缀模型

发布日期：2026-10-20

本版本补上 v2.0.25 没有带出的一项界面修复。子智能体选模型时，如果带前缀的模型已经覆盖同名裸模型，下拉只保留带前缀的那一项。这是兼容性修复。候选阶段不提前声称 CI、tag 或 GitHub Release 已经完成。

## 对用户工作流的直接变化

- 设置里的子智能体模型下拉会同时看当前目录和已登记模型。
- 同一名字既有裸模型又有带前缀模型时，保留带前缀的模型，不再把裸模型再列一次。
- 没有对应前缀的模型仍照常显示。
- 工具活动卡、会话和路线保存行为与 v2.0.25 相同。

## 配置、数据与安全边界

- 不改变权限模式、凭据存储、路线名或会话记录。已有配置和会话可以继续使用。
- 这次只改变下拉里可见的模型名单，不改模型请求实际发往的路线。
- 自动化测试不能代表所有私有研究数据或每一个外部模型供应商都已验证。

## 升级与产物位置

```sh
npm ci
npm run verify:install
npm link
ant-code --version
```

`ant-code --version` 应显示 `2.0.26`。正在运行的 Dashboard 需要重启并刷新浏览器。

## 验证、限制与待完成门禁

- 开发仓已有子智能体前缀筛选的单元测试和浏览器测试。候选阶段的正式仓 `verify:release`、CI、tag 和 GitHub Release 完成后才会记入发布记录。
- 已知限制：这次不补其他未发布的界面实验。最终结论以正式仓同一提交的 CI 和 Release 门禁为准。
